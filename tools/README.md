# Вспомогательные скрипты

Эта папка содержит вспомогательные Python-скрипты для разработки и тестирования функциональности бота.

## Скрипты

### `test_download_tracks.py`

Тестовый скрипт для скачивания треков из плейлистов Яндекс.Музыки и исследования возможностей стриминга.

**Назначение:**
- Проверка работы API Яндекс.Музыки для скачивания треков
- Исследование возможностей стриминга через метод `get_download_info()`
- Анализ ссылок на пригодность для стриминга
- Тестирование функциональности перед интеграцией в бота

**Использование:**

**Режим скачивания (по умолчанию):**
```bash
python tools/test_download_tracks.py
```

**Режим исследования стриминга:**
```bash
python tools/test_download_tracks.py --streaming
# или короткая версия
python tools/test_download_tracks.py -s
```

**Функциональность:**

**Режим скачивания:**
- Получение списка плейлистов пользователя из API
- Выбор плейлиста для скачивания
- Просмотр списка треков в плейлисте
- Выбор диапазона треков для скачивания
- Скачивание треков в папку `.YMcache/`

**Режим исследования стриминга:**
- Получение информации о скачивании через `get_download_info()`
- Анализ структуры объектов download_info
- Извлечение URL для скачивания/стриминга
- Проверка поддержки HTTP Range Requests (необходимо для стриминга)
- Проверка Content-Type (должен быть audio/*)
- Определение пригодности ссылки для стриминга
- Подробное логирование всех найденных данных

**Что проверяется при исследовании стриминга:**
1. **HTTP Range Requests** - поддержка запросов части файла (заголовок `Accept-Ranges: bytes`)
2. **Content-Type** - тип контента (должен начинаться с `audio/`)
3. **Content-Length** - размер файла
4. **Статус код** - должен быть 200 (успешный запрос)

**Как проверить ссылку вручную:**
Если скрипт находит URL, вставьте его в адресную строку браузера. Если откроется встроенный плеер и начнется воспроизведение - ссылка подходит для стриминга.

**Требования:**
- Токен Яндекс.Музыки (переменная окружения `YANDEX_TOKEN` или ввод при запуске)
- Установленные зависимости из `requirements.txt`
- Библиотека `requests` для проверки HTTP заголовков

**Основан на:**
- Пример `player.py` из библиотеки [yandex-music-api](https://github.com/MarshalX/yandex-music-api)
