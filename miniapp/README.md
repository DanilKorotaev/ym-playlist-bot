# Mini App - Музыкальный плеер

Telegram Mini App для воспроизведения плейлистов Яндекс.Музыки.

## Структура

```
miniapp/
├── static/              # Статические файлы
│   ├── index.html       # Главная страница
│   ├── css/
│   │   └── styles.css   # Стили приложения
│   ├── js/
│   │   ├── app.js       # Основная логика приложения
│   │   └── telegram-api.js  # Обертка для Telegram Web App API
│   └── assets/          # Изображения и другие ресурсы
└── README.md            # Этот файл
```

## Локальная разработка

### Вариант 1: Простой HTTP сервер + ngrok (рекомендуется для разработки)

1. **Установите ngrok:**
   ```bash
   # macOS
   brew install ngrok
   
   # Или скачайте с https://ngrok.com
   ```

2. **Зарегистрируйтесь на ngrok.com** (бесплатно) и получите authtoken:
   ```bash
   ngrok config add-authtoken <your-token>
   ```

3. **Запустите локальный HTTP сервер:**
   ```bash
   cd miniapp/static
   python3 -m http.server 8000
   ```

4. **В отдельном терминале запустите ngrok:**
   ```bash
   ngrok http 8000
   ```

5. **Используйте полученный HTTPS URL** (например, `https://xxxx-xx-xx-xx-xx.ngrok-free.app`) в переменной окружения:
   ```bash
   export MINIAPP_URL=https://xxxx-xx-xx-xx-xx.ngrok-free.app
   ```

6. **Перезапустите бота** - кнопка "🎵 Открыть плеер" появится в главном меню.

## Переменные окружения

Добавьте в `.env`:

```env
# URL Mini App (для кнопки Web App)
MINIAPP_URL=https://your-domain.com/miniapp/
```

Если `MINIAPP_URL` не указан, кнопка Web App не будет отображаться в меню.

## Тестирование

1. Запустите бота
2. Откройте бота в Telegram
3. Нажмите кнопку "🎵 Открыть плеер"
4. Mini App должен открыться
5. Нажмите на кнопку загрузки плейлистов (если есть)
6. Проверьте, что данные отправляются в бот через `sendData()`

## Примечания

- **HTTPS обязателен** для Web Apps - Telegram требует HTTPS
- Для разработки используйте ngrok или другой туннель
- Для продакшена нужен реальный домен с SSL сертификатом (Let's Encrypt)
