# Диагностика проблем Mini App с самоподписанным SSL сертификатом

## Проблема

Mini App не открывается или не загружается при использовании самоподписанного SSL сертификата.

## Возможные причины

1. **Telegram блокирует самоподписанные сертификаты** - Telegram может блокировать загрузку Mini App из-за невалидного SSL сертификата
2. **Браузер блокирует небезопасное соединение** - Браузер может блокировать загрузку ресурсов из-за самоподписанного сертификата
3. **CORS проблемы** - Неправильные CORS заголовки могут блокировать запросы
4. **Проблемы с загрузкой статики** - Статические файлы могут не загружаться из-за SSL

## Диагностика

### 1. Проверка загрузки статики

```bash
# Проверка доступности index.html
curl -k https://YOUR_SERVER_IP/

# Должна вернуться HTML страница Mini App
```

### 2. Проверка работы API

```bash
# Проверка API через HTTPS
curl -k https://YOUR_SERVER_IP/api/docs

# Должна вернуться HTML страница Swagger UI
```

### 3. Проверка в браузере

1. Откройте Mini App в Telegram
2. Откройте DevTools (если доступно) или используйте `console.log` в коде
3. Проверьте консоль на наличие ошибок:
   - Ошибки SSL/HTTPS
   - Ошибки CORS
   - Ошибки загрузки ресурсов
   - Ошибки API запросов

### 4. Проверка логов nginx

```bash
# Логи nginx
docker compose logs nginx

# Проверка ошибок
docker compose logs nginx | grep -i error
```

### 5. Проверка логов API

```bash
# Логи API
docker compose logs api

# Проверка ошибок
docker compose logs api | grep -i error
```

## Решения

### Решение 1: Использование Cloudflare Tunnel (рекомендуется для стейджа)

Если самоподписанный сертификат не работает, используйте Cloudflare Tunnel:

```bash
# Установка cloudflared
# macOS: brew install cloudflared
# Linux: скачать с https://github.com/cloudflare/cloudflared/releases

# Запуск туннеля
cloudflared tunnel --url https://YOUR_SERVER_IP:443
```

Скопируйте полученный HTTPS URL и используйте его в `MINIAPP_URL`.

**Преимущества:**
- ✅ Валидный SSL сертификат от Cloudflare
- ✅ Работает из РФ
- ✅ Бесплатно
- ✅ Не требует настройки на сервере

### Решение 2: Использование домена с Let's Encrypt

Если у вас есть домен, настройте Let's Encrypt:

```bash
# Установка certbot
sudo apt install certbot python3-certbot-nginx

# Получение сертификата
sudo certbot --nginx -d your-domain.com
```

### Решение 3: Проверка конфигурации nginx

Убедитесь, что nginx правильно настроен:

```bash
# Проверка конфигурации nginx
docker compose exec nginx nginx -t

# Перезапуск nginx
docker compose restart nginx
```

### Решение 4: Проверка MINIAPP_URL в боте

Убедитесь, что `MINIAPP_URL` правильно установлен:

```bash
# Проверка переменной окружения
docker compose exec bot env | grep MINIAPP_URL

# Должно быть: MINIAPP_URL=https://YOUR_SERVER_IP
```

## Типичные ошибки

### Ошибка: "Failed to fetch"

**Причина:** Проблема с SSL сертификатом или сетью

**Решение:**
- Используйте Cloudflare Tunnel вместо самоподписанного сертификата
- Или получите валидный SSL сертификат (Let's Encrypt)

### Ошибка: "Telegram Web App API не доступен"

**Причина:** Mini App открыт не через Telegram

**Решение:**
- Убедитесь, что открываете через кнопку "🎵 Открыть плеер" в Telegram
- Не открывайте ссылку напрямую в браузере

### Ошибка: "Invalid initData"

**Причина:** Проблема с авторизацией через Telegram

**Решение:**
- Закройте и снова откройте Mini App через кнопку
- Обновите Telegram до последней версии
