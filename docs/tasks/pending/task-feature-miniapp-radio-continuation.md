## Описание

Реализация автоматического переключения на "Мою волну" (радио на основе плейлиста) после завершения воспроизведения плейлиста в Mini App плеере. Если в плейлист добавили новые треки, они автоматически воспроизводятся первыми, затем снова включается "Моя волна".

## Сценарий использования

1. Пользователь воспроизводит плейлист в Mini App плеере
2. Плейлист заканчивается (все треки из очереди воспроизведены)
3. **Автоматически** начинается "Моя волна" (радио на основе этого плейлиста)
4. Если в плейлист добавили новые треки (через бота или другим способом):
   - Новые треки автоматически добавляются в очередь (уже реализовано в `task-feature-auto-queue-update.md`)
   - Новые треки воспроизводятся первыми
   - После новых треков снова включается "Моя волна"
5. Цикл повторяется: плейлист → новые треки (если есть) → "Моя волна" → новые треки → "Моя волна" → ...

## Преимущества

- ✅ **Непрерывное воспроизведение** - музыка не останавливается после завершения плейлиста
- ✅ **Персонализация** - "Моя волна" адаптируется к предпочтениям пользователя
- ✅ **Автоматическое обновление** - новые треки из плейлиста автоматически попадают в очередь
- ✅ **Улучшенный UX** - пользователю не нужно вручную переключаться на радио

### Интеграция с существующей логикой

**Текущая логика обновления очереди:**
- `PlaylistUpdater` проверяет обновления плейлиста каждые 10 секунд
- При обнаружении новых треков добавляет их в конец очереди

**Новая логика:**
- При завершении плейлиста (все треки из очереди воспроизведены)
- Проверяем, включена ли опция "Автоматически включать радио"
- Если да, запрашиваем треки из "Моей волны" на основе плейлиста
- Добавляем треки из радио в очередь
- Продолжаем воспроизведение

**Обработка новых треков при активном радио:**
- Если играет радио и обнаружены новые треки в плейлисте
- Останавливаем добавление треков из радио
- Добавляем новые треки из плейлиста в очередь
- После завершения новых треков снова включаем радио

```python
# miniapp/api/routes.py

@router.get("/radio/start")
async def start_radio(
    playlist_id: int,
    user_id: int = Depends(get_user_id),
    playlist_service: PlaylistService = Depends(get_playlist_service),
    client_manager: YandexClientManager = Depends(get_client_manager)
):
    """Запустить радио на основе плейлиста."""
    # Получаем клиент и сервис
    client = await client_manager.get_client_for_playlist(playlist_id)
    yandex_service = YandexService(client)
    
    # Получаем треки из радио (если метод доступен)
    radio_tracks = await asyncio.to_thread(
        yandex_service.get_radio_tracks_for_playlist,
        playlist_id
    )
    
    if not radio_tracks:
        raise HTTPException(
            status_code=404,
            detail="Radio tracks not available"
        )
    
    # Форматируем треки для ответа
    formatted_tracks = []
    for track_item in radio_tracks:
        formatted_tracks.append({
            "id": yandex_service.extract_track_info(track_item)[0],
            "title": yandex_service.format_track(track_item),
            "artists": yandex_service.get_track_artists(track_item),
            "duration": getattr(track_item.track if hasattr(track_item, 'track') else track_item, 'duration_ms', 0) // 1000,
            "source": "radio"  # Индикатор, что трек из радио
        })
    
    return {"tracks": formatted_tracks}
```
